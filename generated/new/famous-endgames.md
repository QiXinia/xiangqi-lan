# 名局鉴赏 / 打谱分片报告（generated/new/famous-endgames.mjs）

本分片为纯静态中国象棋网页「棋谱库」提供经典江湖排局 / 四大名局数据，**只做名局鉴赏/打谱，不写入 puzzles 限时必胜残局关**。每条起始 FEN 与主线着法均经项目引擎 `js/engine.js` + `js/notation.js` 的 `playLine` 回放校验（脚本 `tmp-verify-famous.mjs`，运行结果 10/10 全 OK，不合格 0 局）。

## 校验口径

- FEN：10 行 `/` 分隔，第 0 行=黑方底线（棋盘最上），第 9 行=红方底线；红大写 `K A B N R C P`，黑小写；末尾 ` r`=红先。
- 合法性：每方恰一个王；仕/士限九宫点；相/象限合法象点；未过河兵卒在偶数列；双王不照面；非行棋方未被将军；行棋方起始未被将；`createState({fen})` 成功且 `legalMoves` 非空。
- 回放：`playLine(state, moves)` 必须 `ok=true`；终局 `status` 如实打印。
- 去重：与 `js/puzzles.js` 现有残局重名检查通过（跨海征东、十面埋伏、丹凤朝阳已在 puzzles classic 章，未再用同名）；分片内 `name` 与 `fen` 唯一。
- 文字统一用「炮/汉」，不用「砲/漢」。

## 去重与纠错记录

- **野马操田**：xqipu 给出的 FEN 原文缺红帅，已补在 `(3,9)`；主线"相七退九"因双相同列歧义改写为"前相退九"。
- **蚯蚓降龙**：起首行 `3ak5` 行宽校正为 `3ak4`。
- **征西**：双炮同在三路(x=6)，首着原文"炮三平四"有歧义，引擎要求"前炮平四"；三路双卒时原文"卒4平5"歧义，按实际局面改写为"前卒平5"/"卒5平4"。
- **千里独行 / 带子入朝 / 火烧连营**：均由主线着法反推 + 引擎 `legalMoves`/`moveNotation` 试错还原 FEN。

## 只给「已验证前缀」的局及原因

- **野马操田（22 着前缀）**：脱帽后进入复杂对攻，现代诠注结论已从「和棋」变为「红先黑胜」，变着极多。
- **带子入朝（20 着前缀）**：黑车占肋后黑方有杀势，网络后续着法错误率高。
- **火烧连营（9 着前缀）**：正传约 200 着，网络着法版本众多，仅保留「弃车—双炮轰宫」著名开场。
- **征西（16 着前缀）**：卒5进1后红帅被黑卒贴将，原谱续着"车三平四"在引擎复核中无法应将，存在诠注分歧，截断于此。
- **停车问路（6 着前缀）**：车三退八抽车后，后续红须平帅解杀、马九退八迂回，着法极长且有诠注分歧，仅保留脱帽开场。
- **金鸡独立（4 着前缀）**：车占中后，后续红仕调整车位、黑双卒围攻，着法极长，仅保留开场。
